# funstuff

Small games and fun projects, published with GitHub Pages.

- [`pinochle/`](pinochle/): three-handed pinochle for three phones. Setup is in [`pinochle/README.md`](pinochle/README.md).
- [`supper/`](supper/): weekly dinner planner. Set a budget, Chicago-area store, diet, allergies and kitchen; get a week of dinners and one aisle-sorted shopping list with an estimated total.
